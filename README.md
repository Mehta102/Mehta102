## 🚀 Currently Building

### 🎮 [Backseater AI](https://github.com/Mehta102/backseater-ai)

A real-time AI commentator that watches live gameplay, detects on-screen events and responds with spoken, context-aware commentary. Built as my final year project, with the hard engineering in latency control and deciding when *not* to speak.

**Focus:** Python, OpenCV, Tesseract OCR, scikit-learn, LLM integration, text-to-speech, real-time pipelines.

### 🤖 Autonomous ROS2 Robot

A simulated mobile robot that navigates unknown environments with no prior map, using a priority-based behaviour architecture: obstacle avoidance, wall following and exploration. Now extending it toward SLAM and autonomous navigation.

**Focus:** ROS2, Gazebo, LIDAR processing, subsumption architecture, control, Python.

### 🪑 [Deskmate AI](https://github.com/Mehta102/DeskMateAI)

A vision-driven tool that analyses a room, scores furniture placement against ergonomic heuristics and generates better layouts.

**Focus:** Python, deep learning, computer vision, Flutter, React, Unity.

### 🌡️ IoT Environment Monitor

ESP32 firmware for live temperature and humidity monitoring, with threshold-based alerting.

**Focus:** C++, ESP32, sensor interfacing, embedded systems, Wokwi simulation.

Most of my work so far is academic and personal projects in AI, perception and robotics. I'm now looking to apply it in a graduate engineering role.
